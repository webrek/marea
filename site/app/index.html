Marea 🌊

Un lenguaje para la web donde las dos fronteras son primitivas del lenguaje, no librerías que cableas.

@server / @client → RPC reactive → signals escrito en Rust v0 de investigación

La tesis

Toda app web cruza dos fronteras a mano: la de red (cliente↔servidor) y la del tiempo (cuándo se recalcula algo). Marea las vuelve parte del lenguaje: el compilador genera el RPC y la reactividad por ti.

Frontera de red. saludar corre en el servidor; el cliente la llama como si fuera local.

// el compilador genera el RPC; no escribes "capa de API"
@server
fn saludar(nombre: String) -> String {
    return concat("Hola desde el servidor, ", nombre);
}

@client
fn main() {
    print(saludar("Marea"));
}

Frontera del tiempo. Asignar a una reactive propaga el cambio solo.

// sin librería: signals/effect son del lenguaje
@client
fn main() {
    reactive mut n = 0;
    reactive doble = n * 2;
    effect { print(doble); }
    n = n + 1;   // imprime 0, luego 2
}

Rendimiento

Marea tiene dos backends: TypeScript (frontera + reactividad) y WebAssembly (cómputo). Para un kernel fib, el WASM va a ras de nativo.

Marea es un lenguaje de programación v0 de investigación escrito en Rust. No es para producción todavía: la idea es demostrar que las fronteras de la web caben en el lenguaje.
